# Пульс — техно голосом

Говоришь по-русски — собирается техно-трек. Скажи «сделай техно», «добавь кислотный бас», «нарастание», «дроп», и всё заиграет сразу.

Мелодию можно напеть, а ритм отбить битбоксом. Приложение превратит голос в ноты и барабаны.

«Пульс» сам сочиняет трек целиком на 1–5 минут: интро, брейки, подъёмы, ямы и дропы по сценарию жанра. Всё потом можно поправить.

Все звуки синтезируются прямо в браузере, без сэмплов и без серверов. У каждого инструмента несколько тембров: бочки 909, 808, хард и индастриал, кислотный бас 303, бас 808, риз, хаус-бас, пэды, хор, клавиши, колокол. Тембры собраны в наборы под жанры. Ничего не нужно скачивать.

**Открыть сразу, в том числе с телефона:** https://zuevilia808-collab.github.io/pulse/

## Запуск

Нужны [Node.js](https://nodejs.org) и Google Chrome.

```bash
node server.js
```

Откроется Chrome с адресом http://127.0.0.1:7870. На Windows можно просто запустить `start.bat`.

Нажми на микрофон, разреши доступ и говори.

> Голосовые команды распознаёт Chrome (Web Speech API), для этого нужен интернет. Звук, ноты, битбокс и запись работают без интернета. Команды можно и печатать в поле под микрофоном.

Можно сказать несколько команд в одной фразе: «добавь бочку, хэты на офбит и кислотный бас».

«Другой …» меняет звук инструмента, а «новый …» — его рисунок.

## Без голоса

- **Клетка паттерна:** нажатие ставит или убирает удар. **Удержание** (на компьютере — правая кнопка мыши) открывает маленькое окошко: выбрать ноту, акцент, глайд и длину.
- **Название дорожки** — выбрать её звук. **S** — соло, можно включить у нескольких дорожек сразу.
- **Кнопки «− Кислота +», «− Румбл +»** и другие под полем ввода — одна кнопка на оба направления.
- **«Гармония» над секвенсором:** по какому кругу аккордов идут бас, аккорды и мелодия и как часто меняется аккорд. Аккорд, который звучит, подсвечивается.
- **Карточка «Звук»:**
  - наборы под жанр;
  - звук каждого инструмента;
  - пульт с вертикальными фейдерами, как у диджея: громкость каждой дорожки, фильтры, кислота, румбл, эхо, реверб, свинг. Всё видно сразу, листать не нужно.

## Трек целиком

«Сочинить трек» раскладывает паттерн на блоки по 16 тактов по правилам жанра. Правила собраны из разборов продюсеров: Underdog, Yan Cook и других.

- **Каждый вариант — свой номер.** «Другой вариант» (или фраза «другой вариант») сочиняет новую аранжировку того же паттерна. «Вариант 777» возвращает конкретный.
- **Девять форм трека:** классика, две волны, трилогия брейка, медленный разогрев, большой брейк, плато, DJ-тул, «сразу в бой», «из тишины». У каждого жанра свои любимые.
- **Каждый блок отличается:**
  - у партий есть рисунки A, B и C, и хэты с перкуссией «переключают передачи»;
  - инструменты вступают со сдвигом;
  - на стыках звучат сбивки, томы, дробь бочки, заикание, броски эха и реверба, «выключение», ложный дроп;
  - иногда блок начинается «без низа» или «минимумом»;
  - посреди трека бывают вставки на 1–2 такта.
- **Полиметр:** перкуссия и мелодия иногда играют фразы длиной 3–10 шагов, которые сдвигаются относительно такта.
- **Главный герой:** один инструмент разгорается и затухает через весь трек.
- **Гармония двигается:** бас, аккорды и мелодия идут по кругу аккордов. В брейке аккорды тянутся дольше или идут по своему кругу, в подъёме лезут вверх.
- **Отыгрыш в яме и брейке:** каждый такт свой — мотив, его вариации, ответ и пробежки, всё в ладу и в сетке.
- **Свобода, как у человека за пультом:**
  - бас уходит на октаву или квинту;
  - перед сменой аккорда звучит толчок;
  - хэты бьют с живой динамикой;
  - фильтры медленно «гуляют».
- **Подъём без дроби хэтов:** напряжение дают аккорды, фильтр и шум.

Всё можно править:
- нажатие на часть меняет длину, метку в начале, начало, разворот в конце, фильтр, гармонию и смену аккордов, включает отыгрыш «каждый такт свой», а ещё есть «пересочинить часть»;
- нажатие на клетку включает или выключает инструмент, удержание открывает громкость, рисунок A/B/C и место вступления;
- переключатель A/B/C в «Паттерне» показывает и даёт редактировать рисунки B и C.

Правила, по которым строится трек, описаны в [ARRANGEMENT.md](ARRANGEMENT.md). Это инструкция для человека и для нейросети.

## Запись

- **Весь трек:** кнопка «Сохранить WAV» или слово «сохрани». Трек собирается быстрее, чем играет: минута примерно за 10 секунд. Файл падает в «Загрузки».
- **Живое исполнение:** «начни запись» → «стоп запись». Записывается всё, что звучало, в WAV.

## Устройство

| Файл | Что делает |
|---|---|
| `js/engine.js` | синтез инструментов, секвенсор, эффекты, проигрывание трека по частям, запись WAV |
| `js/sounds.js` | библиотека звуков и наборы под жанры |
| `js/arrange.js` | сценарии треков: части, переходы, гармония, отыгрыш, живые отступления, энергия |
| `js/commands.js` | разбор русских команд в действия |
| `js/listen.js` | микрофон, распознавание напетых нот и битбокса |
| `js/music.js` | лады, круги аккордов, паттерны, генераторы партий, жанры (включая Witch House и хаус) |
| `js/voice.js` | распознавание речи в Chrome |
| `js/viz.js` | визуализация |
| `js/app.js` | интерфейс и связка всего вместе |
| `server.js` | мини-сервер без зависимостей: Chrome запоминает разрешение на микрофон только для адреса, а не для файла |
