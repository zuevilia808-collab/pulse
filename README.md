# Пульс — техно голосом

Говоришь по-русски — собирается техно-трек. Скажи «сделай техно», «добавь кислотный бас», «нарастание», «дроп», и всё заиграет сразу.

Мелодию можно напеть, а ритм отбить битбоксом. Приложение превратит голос в ноты и барабаны.

«Пульс» сам сочиняет трек целиком на 1–5 минут: интро, брейки, подъёмы, ямы и дропы по сценарию жанра. Всё потом можно поправить.

Все звуки синтезируются прямо в браузере, без сэмплов и без серверов. У каждого инструмента несколько тембров: бочки 909, 808, хард и индастриал, кислотный бас 303, бас 808, риз, пэды, хор, колокол. Тембры собраны в наборы под жанры. Ничего не нужно скачивать.

**Открыть сразу, в том числе с телефона:** https://zuevilia808-collab.github.io/pulse/

## Запуск

Нужны [Node.js](https://nodejs.org) и Google Chrome.

```bash
node server.js
```

Откроется Chrome с адресом http://127.0.0.1:7870. На Windows можно просто запустить `start.bat`.

Нажми на микрофон, разреши доступ и говори.

> Голосовые команды распознаёт Chrome (Web Speech API), для этого нужен интернет. Звук, ноты, битбокс и запись работают без интернета. Команды можно и печатать в поле под микрофоном.

Можно сказать несколько команд в одной фразе: «добавь бочку, хэты на офбит и кислотный бас».

«Другой …» меняет звук инструмента, а «новый …» — его рисунок.

## Без голоса

- **Клетка паттерна:** нажатие ставит или убирает удар. **Удержание** (на компьютере — правая кнопка мыши) открывает маленькое окошко: выбрать ноту, акцент, глайд и длину.
- **Название дорожки** — выбрать её звук. **S** — соло, можно включить у нескольких дорожек сразу.
- **Кнопки «− Кислота +», «− Румбл +»** и другие под полем ввода — одна кнопка на оба направления.
- **Карточка «Звук»** — наборы под жанр, звук каждого инструмента и ручки.

## Трек целиком

«Сочинить трек» раскладывает паттерн на части по сценарию жанра:
- над частями виден график энергии;
- если нажать на часть, можно поменять её длину, переход в начале и в конце, фильтр и гармонию, а ещё сыграть отсюда, сдвинуть, скопировать или удалить;
- клетки под частями показывают, какой инструмент в какой части играет: нажатие включает или выключает, удержание переключает «легко / полностью / плотно».

Правила, по которым строится трек, описаны в [ARRANGEMENT.md](ARRANGEMENT.md). Это инструкция для человека и для нейросети.

## Голос → ноты

- **Напой партию.** После отсчёта «4-3-2-1» напой или промычи один такт. Высота тона распознаётся алгоритмом YIN. Каждый слог встаёт на ближайший шаг, тоника напетого переносится в тональность трека, а плавные переходы становятся глайдами баса.
- **Битбокс.** «бум» — бочка, «тс» — хэт, «пщ» или «ка» — клэп. Удары находятся по резкому росту энергии в 24 частотных полосах и различаются по тембру.
- Пока ты поёшь, бит затихает, чтобы микрофон его не ловил. В наушниках можно включить переключатель «Я в наушниках», и бит будет играть.

## Запись

- **Весь трек:** кнопка «Сохранить WAV» или слово «сохрани». Трек собирается быстрее, чем играет: минута примерно за 10 секунд. Файл падает в «Загрузки».
- **Живое исполнение:** «начни запись» → «стоп запись». Записывается всё, что звучало, в WAV.

## Устройство

| Файл | Что делает |
|---|---|
| `js/engine.js` | синтез инструментов, секвенсор, эффекты, проигрывание трека по частям, запись WAV |
| `js/sounds.js` | библиотека звуков и наборы под жанры |
| `js/arrange.js` | сценарии треков: части, переходы, энергия |
| `js/commands.js` | разбор русских команд в действия |
| `js/listen.js` | микрофон, распознавание напетых нот и битбокса |
| `js/music.js` | лады, паттерны, генераторы партий, жанры (включая Witch House) |
| `js/voice.js` | распознавание речи в Chrome |
| `js/viz.js` | визуализация |
| `js/app.js` | интерфейс и связка всего вместе |
| `server.js` | мини-сервер без зависимостей: Chrome запоминает разрешение на микрофон только для адреса, а не для файла |
